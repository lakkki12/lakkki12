## Projects

### [CUDA Huffman Compression](https://github.com/lakkki12/huffman-cpu-vs-gpu)
**C++ · CUDA · Parallel computing**

A CPU and GPU implementation of canonical Huffman compression and decompression. I built it while learning computer architecture and exploring how CUDA programs divide work between the CPU and GPU.

The project covers frequency counting, encoding, decoding, and the practical trade-offs involved in GPU acceleration.

### [LexAgent](https://github.com/lakkki12/MultiAgent-Debate-Framework-for-Hallucination-Reduction-in-Legal-Al)
**Python · LangGraph · RAG · LLMs**

A research project investigating whether structured multi-agent debate and citation checking can improve the grounding of legal AI responses.

We started exploring the idea after reading about fabricated legal citations used in court. The work also made us think more carefully about evaluation and the latency costs of additional verification.

### [Stock Trading Simulator](https://github.com/lakkki12/STOCK_TRADER)
**React · JavaScript · REST APIs**

A React-based project for exploring market data, candlestick patterns, simulated trading, and basic backtesting using Alpha Vantage data.

I built it to learn more about trading logic and working with external APIs. It's a learning project rather than a production trading platform.

### BeatPulse
**AI-generated software experiment · Android · Web**

**Built entirely by AI from my initial product idea.** I wanted to see whether an AI-driven development process could produce a useful attendance and field-operations application for a family business.

It includes an Android app and a web dashboard for attendance, shifts, and field visits. The application and source code aren't public because they relate to real business operations.
